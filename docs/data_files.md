# 데이터 파일 구조 및 역할

## 파일 목록 및 생성 주체

```
python/data/animal_skeletons/
    spider.json                  ← AnimPoseExporter 생성 (axis/ROM 수동 수정 가능)
    bone_map_spider.json         ← AnimPoseExporter 생성 (axis 수동 수정 가능)
    spider_poses.json            ← AnimPoseExporter 생성

python/data/mappings/
    spider_mapping.json          ← generate_mappings.py 생성
    spider_body_mapping.json     ← 수동 작성 (영구 파일)
    spider_triggers_lda.json     ← lda_triggers.py 생성
```

## spider.json — 골격 정의

### 역할
- AnimalControllerEditor가 읽어 JointEntry의 axis/minAngle/maxAngle 세팅
- generate_mappings.py가 읽어 ROM 범위 파악
- main.py가 읽어 transform_clamped() 시 ROM 클리핑

### 구조
```json
{
  "animal_name": "spider",
  "bilateral": true,          ← 양손/단손 모드
  "joints": [
    {
      "id": "bone",
      "parent": "body",
      "dof": 1,               ← 자유도 수
      "min_angle": -180.1,    ← REST 기준 최소 회전각 (°)
      "max_angle": 184.1,     ← REST 기준 최대 회전각 (°)
      "axis": "X",            ← 회전 축 (AnimPoseExporter 자동 감지, 수동 수정 가능)
      "rest": 0.0
    },
    ...
  ],
  "chains": [
    ["l_leg", "l_bone_012", "l_bone_013"],    ← 체인: [루트, 미드, 팁]
    ["l_leg_001", "l_bone_009", "l_bone_010"],
    ...
  ]
}
```

### axis 필드 주의사항
AnimPoseExporter가 자동으로 "어느 Euler 성분이 가장 많이 변하는가"로 결정.  
하지만 Unity 로컬 좌표계에 따라 시각적으로 다른 방향으로 적용될 수 있음.  
`bone`과 `bodyik_001`은 Z→X로 수동 변경됨 (Death 뒤집기 문제, 미검증).

### chains 필드
`auto_chains.py`가 spider_mapping.json의 chain 구조를 보고 자동 생성하거나 수동으로 입력.  
AnimPoseExporter는 chains를 건드리지 않고 보존.

## bone_map_spider.json — Unity Transform 경로 맵

### 역할
- AnimalControllerEditor가 읽어 Transform.Find() 경로 파악
- keyframe_engine.py의 `_load_bone_axes()`가 읽어 scalar→xyz 변환 축 파악

### 구조
```json
{
  "_usage": "auto-generated by AnimPoseExporter",
  "animal": "spider",
  "rest_anim": "Idle",
  "margin_deg": 5.0,
  "joint_map": {
    "bone": {
      "unity_path": "Spider/Bone",   ← Transform.Find()에 사용할 경로
      "axis": "X"                    ← 이 관절의 회전 축 (수동 X로 변경)
    },
    "l_leg": {
      "unity_path": "Spider/Bone/L.Leg",
      "axis": "Z"
    },
    ...
  }
}
```

### unity_path 형식
루트 GameObject(Spider)부터 시작하는 계층 경로.  
AnimalControllerEditor는 `root.Find(path)` 또는 `root.Find(path.Substring(firstSlash+1))`로 탐색.

### axis 수동 수정
AnimPoseExporter가 자동 감지하지만, 시각적으로 잘못된 축이면 수동으로 수정 필요.  
변경 후 반드시 AnimalControllerEditor "JointEntry 전체 자동 생성" 재실행.

## spider_poses.json — 애니메이션 프레임 데이터

### 역할
- keyframe_engine.py의 `_build_keyframes()`가 읽어 `animal_poses` 구성
- `get_sequential_pose()`에서 프레임 보간에 사용

### 구조
```json
[
  {"_anim": "Attack1", "_frame": 0, "l_leg": 0.0, "r_leg": 0.0, "bone": 0.0, ...},
  {"_anim": "Attack1", "_frame": 1, "l_leg": -17.2, "r_leg": 17.8, ...},
  ...
  {"_anim": "Death", "_frame": 1, "bone": 0.04, "bodyik_001": 0.0, ...},
  {"_anim": "Death", "_frame": 12, "bone": 171.54, "bodyik_001": -71.55, ...},
  ...
]
```

### 값의 의미
각 값 = **Rest 포즈(Idle) 기준 delta 회전각(°)**, 해당 관절의 dominant axis 방향.  
예: `"bone": 171.54` → bone을 X축(현재 설정)으로 171.54° 추가 회전.

### 현재 포함된 애니메이션
Attack1, Attack2, Death, Idle, Walk 등.  
(이전에 WalkBack, Death가 제거됐다가 Death는 다시 필요해서 재추가)

## spider_mapping.json — 최적화된 손↔관절 매핑

### 역할
- KeyframeMappingEngine이 읽어 역변환 트리거 계산
- MappingEngine이 읽어 direct 매핑
- AnimalControllerEditor가 읽어 allowed 관절 필터링

### 구조
```json
{
  "animal": "spider",
  "mode": "bilateral",
  "mapping": {
    "l_leg": {
      "hand_dof_idx": 7,           ← _HAND_DOF_NAMES[7] = "index_mcp"
      "hand_dof_name": "index_mcp",
      "scale_factor": 1.95,        ← 손 DOF 변화량 × scale = 관절 각도
      "Q_score": 8.2,
      "hand": "left"               ← 어느 손
    },
    ...
  },
  "reference_pose_H": {
    "left": {"wrist_flex": 12.3, ...},
    "right": {"wrist_flex": 11.8, ...}
  }
}
```

### 포함 관절 (24개)
왼손 체인: l_leg, l_leg_001, l_leg_002, l_leg_003 + 각 l_bone 중/말단  
오른손 체인: r_leg, r_leg_001, r_leg_002, r_leg_003 + 각 r_bone 중/말단

### 제외 관절
- IK 타겟: l/r_leg_ik_005/008/011, l_legik_015
- body_mapping 관절: bone, bodyik_001, atack1
- 보조 뼈: ass, bone_002, l/r_bone_014

## spider_body_mapping.json — 몸통 관절 수동 매핑 (수동 작성)

### 역할
- main.py의 continuous 모드에서 body 관절에 0을 전송하기 위한 목록
- AnimalControllerEditor에서 body 관절을 allowed에 포함시키기 위한 목록
- generate_mappings.py에서 body 관절을 메인 매핑에서 제외하기 위한 기준

### 구조
```json
{
  "animal": "spider",
  "description": "몸통 본 수동 매핑 — wrist DOF 고정 배정",
  "mapping": {
    "bone": {
      "hand_dof_idx": 0,
      "hand_dof_name": "wrist_flex",
      "scale_factor": 2.5,
      "hand": "right",
      "axis": "X"               ← 현재 X (Death 뒤집기 실험)
    },
    "bodyik_001": {
      "hand_dof_idx": 1,
      "hand_dof_name": "wrist_dev",
      "scale_factor": 1.5,
      "hand": "right",
      "axis": "X"
    },
    "atack1": {
      "hand_dof_idx": 2,
      "hand_dof_name": "wrist_rot",
      "scale_factor": 2.5,
      "hand": "right",
      "axis": "Y"               ← Y축 (좌우 회전)
    }
  }
}
```

### 현재 동작 방식
continuous 모드: main.py가 이 파일의 관절들에 `{"x":0,"y":0,"z":0}` 명시 전송 (직결 없음).  
action(Death) 모드: keyframe 데이터가 bone/bodyik_001 값을 채우므로 덮어쓰지 않음.  
atack1은 keyframe에서도 항상 제거(`joints_kf.pop("atack1", None)`).

## spider_triggers_lda.json — LDA 트리거 (lda_triggers.py 생성)

### 역할
main.py가 읽어 Attack1/Attack2/Death 트리거 판단에 사용.

### 구조
```json
{
  "left_dof_indices": [3, 4, 7, 8, 10, 11, ...],    ← 매핑된 DOF 인덱스
  "right_dof_indices": [3, 4, 7, 8, ...],
  "triggers": {
    "Attack1": {
      "w_left":  [0.0, 0.0, ..., 0.12, ...],        ← LDA 가중치 벡터 (20차원)
      "w_right": [...],
      "separation": 31.96,                            ← idle/action 클래스 분리도
      "direction": "positive"
    },
    "Attack2": { ... },
    "Death":   { ... }
  }
}
```

### LDA 판단 로직 (main.py)
```python
thr = separation * 0.5 * ATTACK_THRESHOLD   # 기본 thr = separation/2
score = w_left[l_idx] @ delta_l[l_idx] + w_right[r_idx] @ delta_r[r_idx]
# delta = current_hand - reference_hand

if direction == "positive" and score >= thr: → 트리거
if direction == "negative" and score <= -thr: → 트리거
```

## 파일 의존성 다이어그램

```
AnimPoseExporter (Unity)
    │
    ├──→ spider.json
    ├──→ bone_map_spider.json
    └──→ spider_poses.json
              │
              ▼
    generate_mappings.py
              │
    +---------+----------+
    │                    │
    ▼                    ▼
spider_mapping.json   (+ spider_body_mapping.json 수동)
    │
    ▼
lda_triggers.py
    │
    ▼
spider_triggers_lda.json
    │
    ▼
main.py (런타임)
    ├── spider_mapping.json      → MappingEngine
    ├── spider_poses.json        → KeyframeMappingEngine
    ├── bone_map_spider.json     → keyframe_engine _load_bone_axes
    ├── spider_body_mapping.json → body 관절 목록
    └── spider_triggers_lda.json → LDA 트리거
```
