[양식 1] 과제계획서
[캡스톤디자인 과제계획서]

과 제 명: RGB 웹캠 기반 비인간형 동물 아바타의 실시간 손 제어 시스템

1. 과제 개요
   가. 과제 선정 배경 및 필요성

   가상 환경에서 비인간형 동물 아바타(거미, 말 등)를 제어하려면 일반적으로 Depth 카메라나 VR 헤드셋 등 고가의 특수 장비가 필요하다. Cheng et al.이 제안한 HandAvatar(CHI 2023)는 정수계획법(ILP)을 활용하여 손 관절과 동물 관절 간의 최적 매핑을 자동 탐색하는 최초의 체계적 프레임워크이나, (1) Oculus Quest 2의 Depth 카메라에 의존하고, (2) 소스코드가 공개되지 않았으며, (3) 아바타의 이동(Locomotion)을 수동 제스처 등록에만 의존한다는 한계가 있다.

   이러한 한계를 해결하여, 일반 RGB 웹캠 하나만으로 비인간형 동물 아바타를 실시간 제어할 수 있는 시스템을 개발할 필요가 있다. 이는 특수 장비 없이도 가상 아바타 제어를 가능하게 하여 HCI 분야의 접근성을 높이는 데 기여할 수 있다.

   나. 과제 주요내용

   (1) HandAvatar 논문의 ILP 기반 매핑 최적화 알고리즘을 논문 수식만으로 독립 재구현
   (2) Depth 카메라 대신 RGB 웹캠과 MediaPipe HandLandmarker를 활용한 20-DOF 손 관절 추출 방식 설계
   (3) Direct/Keyframe/Blend 세 가지 런타임 제어 방식 구현
   (4) Walk cursor 기반 속도 추출 + 머리 방향/시선 추적 기반 방향 제어로 Locomotion 자동화
   (5) Python-Unity WebSocket 연동을 통한 실시간 파이프라인 구축

2. 과제 목표
   가. 최종결과물의 목표

   [정량적 목표]
   - ILP 매핑 품질 지표 Q score 양수 달성 (목표: Q > 5.0)
   - K=100 서브샘플링으로 논문 대비 계산 시간 40배 이상 단축
   - 2D 이미지 좌표 기반 손가락 각도 측정 안정성 ±5° 이내
   - 60fps 실시간 제어 달성 (소비자급 하드웨어 기준)

   [정성적 목표]
   - 논문 수식-코드 매칭률 90% 이상
   - 거미·말 2종 이상 동물의 실시간 제어 시연
   - Locomotion 자동화(이동+방향 제어) 동작 확인

   나. 최종결과물의 세부 내용 및 구성

   (1) Python 백엔드: 손 추적(MediaPipe), 매핑 엔진(Direct/Keyframe/Blend), 로코모션 매퍼, WebSocket 서버
   (2) Unity 프론트엔드: AnimalController(관절 제어), AnimalLocomotion(이동), GazeNavigator(시선 제어), WebSocketClient
   (3) 오프라인 도구: AnimPoseExporter(포즈 데이터 추출), ILP 솔버(PuLP+CBC), 매핑 JSON 생성기
   (4) 데모 시스템: 거미(24관절, Walk/Attack/Death), 말(29관절, Walk/Eat) 실시간 제어

3. 기대효과 및 활용방안

   - 고가의 Depth 카메라나 VR 장비 없이 일반 웹캠만으로 비인간형 아바타 제어가 가능해져, 가상현실 콘텐츠의 접근성이 크게 향상됨
   - 코드 미공개 논문의 독립 재구현 방법론을 제시하여, 학술 재현성(Reproducibility) 연구에 기여
   - 20-DOF 기하학적 추출 방식과 서브샘플링 기법은 HandAvatar 이외의 손 기반 아바타 제어 시스템에도 범용 적용 가능
   - 향후 사용자 연구(Embodiment 평가)의 기반 시스템으로 활용 가능

4. 수행 방법
   가. 과제수행을 위한 도구적 방법

   - 개발 환경: Python 3.10 (conda), Unity 2022.3 LTS, C#
   - 손 추적: MediaPipe HandLandmarker (RGB 웹캠)
   - 매핑 최적화: PuLP + CBC (정수계획법 솔버)
   - 통신: WebSocket (ws://localhost:8765, JSON 60fps)
   - 시선 추적: eyetrax 라이브러리 (독립 포트 8766)
   - 형상관리: Git + GitHub

   나. 참여인원 및 역할

   강채원 (1인 개발): 알고리즘 설계/구현, Python 백엔드, Unity 프론트엔드, 시스템 통합, 테스트 전체 담당

   다. 과제수행 계획(실습비 사용계획 포함)

   - 실습비: 웹캠 구매, 발표자료 인쇄 등 기본 비용 사용 계획
